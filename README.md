# Можно ли доверять LLM в задачах классического машинного обучения

Экспериментальное сравнение пяти моделей на задачах классического ML:
GigaChat-2-Max, YandexGPT Pro 5.1, DeepSeek-V4-Pro, Qwen3 8B и Королёв ИИ К5.

## Состав эксперимента

- **38 задач**: расчёты (A), утверждения с обоснованием (B), выбор метода (C),
  генерация кода (D), задачи-ловушки (F).
- **190 основных ответов** — по 38 от каждой модели.
- **Тип E** — классификация 200 тестовых строк AI4I 2020 с 0, 5 и 20
  примерами в промпте; всего 3000 ответов пяти моделей.
- **Гипотезы** — H1 (изменение чисел), H6 (пошаговое рассуждение),
  H9 (изменение ответа после возражения).
- **Метрики** — точность и доверительные интервалы, тест Макнемара,
  согласие проверяющих, запускаемость кода, F1 редкого класса,
  balanced accuracy, калибровка уверенности, токены, задержка и стоимость.

## Структура проекта

```text
.
├── analysis.ipynb                 # Основные расчёты, таблицы и графики
├── hypotheses.md                  # Прогнозы и критерии проверки гипотез
├── requirements-analysis.txt      # Окружение для офлайн-анализа
├── requirements.txt               # Исходный список версий библиотек
├── MANIFEST.sha256                # Контрольные суммы сохранённого среза
├── config/                        # Настройки эксперимента и моделей
├── data/                          # Задачи, датасет и эталонные решения
├── grading/                       # Листы оценивания и материалы проверок
├── logs/                          # Первичные журналы запросов и ответов
├── results/                       # Ответы, исполнения кода и сводные метрики
│   ├── d_code/                    # Программы, извлечённые из ответов моделей
│   └── korolev/                   # Сохранённые данные Королёва ИИ
├── report/
│   └── figures/five_models/       # Графики пяти моделей
└── src/                           # Код эксперимента и обработки результатов
```

### Настройки и данные

| Файл | Назначение |
|---|---|
| `config/models.json` | Идентификаторы моделей, провайдеры и параметры подключения |
| `config/experiment.json` | Seed, температура, режимы эксперимента и параметры типа E |
| `config/pricing.json` | Тарифы для расчёта стоимости |
| `config/hypotheses_provenance.json` | Сведения о коммите и времени фиксации гипотез |
| `config/korolev.json` | Метаданные платформы Королёв ИИ |
| `data/tasks.jsonl` | Основной банк задач с эталонами и рубриками |
| `data/tasks_dev.jsonl` | Пять задач для отладки промпта, не входящих в оценку |
| `data/refs/` | Расчётные эталоны задач A/F |
| `data/d_reference/` | Эталонные программы задач D |
| `data/ai4i2020.csv` | Исходный датасет AI4I 2020 |
| `data/e_split.json` | Фиксированные индексы теста и наборов примеров |

### Основные модули

| Модули в `src/` | Назначение |
|---|---|
| `llm.py`, `prompts.py` | Единый интерфейс запросов, журналирование и шаблоны промптов |
| `bank.py` | Проверка банка задач и работа с эталонами |
| `run_bank.py`, `run_extra.py` | Основной прогон и режимы проверки гипотез |
| `run_classifier.py`, `typeE.py`, `typeE_metrics.py` | Классификация строк, классические модели и метрики E |
| `parse.py`, `grade.py`, `autograde.py` | Извлечение ответов и автоматическое оценивание |
| `exec_code.py`, `blind.py` | Исполнение программ D и подготовка листов проверки |
| `analysis.py`, `notebook_data.py` | Статистика, графики и объединение данных пяти моделей |
| `korolev.py`, `run_korolev.py`, `korolev_comparison.py` | Подключение Королёва, прогон и обработка его результатов |
| `checks.py`, `manifest.py`, `provenance.py` | Проверки комплектности и метаданные эксперимента |
| `parser_review.py`, `d_review.py` | Техническая сверка парсера и чек-листа кода |
