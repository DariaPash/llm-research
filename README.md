# ЛР3. Можно ли доверять LLM в задачах классического машинного обучения

Экспериментальное сравнение четырёх моделей на задачах классического ML:
GigaChat-2-Max, YandexGPT Pro 5.1, DeepSeek-V4-Pro и Qwen3 8B.

## Состав эксперимента

- 38 задач: расчёты (A), утверждения с обоснованием (B), выбор метода (C),
  генерация кода (D), задачи-ловушки (F).
- Тип E: классификация строк AI4I 2020 с 0, 5 и 20 примерами.
- Гипотезы H1, H6 и H9; критерии зафиксированы в `hypotheses.md`.

## Структура проекта

- `config/` — настройки эксперимента и моделей.
- `data/` — задачи, датасет и эталонные решения.
- `src/` — код эксперимента и обработки результатов.
- `logs/` — первичные журналы запросов и ответов.
- `grading/` — листы оценивания и материалы проверок.
- `results/` — ответы, результаты исполнения и сводные метрики.

## Окружение

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-analysis.txt
```
